# PersonalLangMaster — подробный план реализации

Персональный ИИ-репетитор английского для себя и семьи. Android, Kotlin, Compose M3,
Gemini Live API (аудио + текст, **без видео**).

Документ описывает продукт, архитектуру, модель данных, каталог настроек, промпт-ядро,
дизайн экранов и пошаговые этапы работ. Обновляется по мере реализации.

---

## 0. Зафиксированные решения

| Вопрос | Решение |
| :-- | :-- |
| Изучаемый язык | Только английский (US/UK-варианты акцента у тренера) |
| Пользователи | Своя установка на каждом телефоне, один профиль на устройство |
| Ключ Gemini | Вводится пользователем в настройках, хранится зашифрованным. В APK ключа нет |
| Голосовой режим | Live API (WebSocket) + push-to-talk, ручное управление активностью |
| Исправление ошибок | Настраиваемый ползунок строгости (5 уровней), влияет и на момент, и на глубину поправок |
| Модули | Разговор, словарь с интервальным повторением, ролевые сценарии, тренажёр произношения, грамматика с упражнениями |
| Уровень | Стартовый голосовой тест + автокоррекция, с возможностью жёстко зафиксировать вручную |
| Расходы | Счётчик минут/токенов/долларов + дневной и месячный лимит на профиль |
| Язык интерфейса | Русский UI, язык объяснений переключается (ru/en) |
| История урока | Настраивается в профиле: транскрипт всегда, аудио — по тумблеру |
| Мотивация | Напоминания, стрик, дневные цели, графики прогресса |
| Экран урока | Субтитры + большая кнопка микрофона, карточки поправок |
| Модель | Native audio по умолчанию (живая интонация), модель выбираема в настройках |
| Персона тренера | Готовые персоны + тонкая настройка поверх (голос, акцент, темп, характер, свой промпт) |
| Оффлайн | Словарь, повторения, история, прогресс работают без сети |
| Порядок работ | Сначала каркас, профиль, БД и настройки; ИИ подключаем следующим этапом |

## 1. Продуктовая концепция

### Учебный цикл

```
   ┌──────────────────────────────────────────────────────────┐
   │                                                          │
   ▼                                                          │
Разговор с тренером (Live)                                    │
   │  ├─ мгновенные мягкие поправки по ползунку строгости     │
   │  └─ тренер вызывает функции: записать слово, отметить    │
   │     ошибку, поднять/опустить сложность                   │
   ▼                                                          │
Разбор после урока (текстовый вызов, structured JSON)         │
   │  ├─ список ошибок: грамматика / лексика / произношение   │
   │  ├─ оценка CEFR за урок + беглость, точность, диапазон   │
   │  └─ 5–10 слов и выражений «взять в актив»                │
   ▼                                                          │
Материал раскладывается по модулям                            │
   ├─ слова и фразы  → словарь (SRS)                          │
   ├─ грамматика     → темы + сгенерированные упражнения      │
   └─ фонемы         → тренажёр произношения                  │
   ▼                                                          │
Повторения и дриллы между уроками (работают оффлайн)          │
   │                                                          │
   └─────────────── профиль ученика обновляется ──────────────┘
```

Главный принцип: **всё, что делает приложение, питается реальными ошибками ученика**.
Никаких абстрактных курсов — темы, упражнения и карточки берутся из его же разговоров.

### Профиль ученика (то, что делает тренера «своим»)

Хранится и подставляется в системный промпт каждого урока:

- уровень CEFR (общий + отдельно speaking / listening / grammar / vocabulary);
- топ-10 актуальных ошибок с частотой и датой последнего повтора;
- проблемные фонемы;
- активный словарный запас (слова в статусе learning/mature);
- интересы и цели («работа в IT», «поездка в Лондон», «сериалы без субтитров»);
- предпочтения по стилю общения и строгости;
- краткие резюме последних трёх уроков.

### DI

Hilt в проекте нет. Для приложения такого размера достаточно **ручного `AppContainer`**,

Если позже захочется Hilt — точка входа одна, миграция дешёвая.

### Что поправить в текущем скелете

| Проблема | Почему важно | Действие |

| `JavaVersion.VERSION_11` | Современные AGP/Compose ожидают 17 | Поднять до 17 |
| Compose BOM `2024.09.00` | Старее, чем adaptive 1.3 и Navigation3 1.0 | Обновить |

## 4. Каталог настроек

Экран «Настройки» — секции со строками `SettingRow` (иконка, заголовок, текущее значение),
каждая раскрывается в подэкран. Сверху — поиск по настройкам.

### 4.1 Тренер

- **Персона** — пресеты: `Friendly Buddy` (расслабленный, поддерживающий),
  `Strict Teacher` (академичный, придирчивый), `Business Coach` (деловой английский),
  `Chatty Native` (быстрая живая речь, идиомы), `Kids Tutor` (простые слова, много похвалы).
- **Голос** — список голосов Live API (Puck, Charon, Kore, Fenrir, Aoede, Zephyr, Leda, Orus…)
  с кнопкой «прослушать пример».
- **Акцент** — American / British / Neutral (влияет на промпт и на подачу фонетики).
- **Темп речи** — 5 позиций от «очень медленно, как для новичка» до «как с носителем».
- **Многословность** — короткие реплики / средние / развёрнутые объяснения.
- **Имя тренера** и обращение к ученику.
- **Свой системный промпт** (advanced) — добавляется к сгенерированному; рядом кнопка
  «показать итоговый промпт» для отладки.

### 4.2 Методика

- **Строгость исправлений** — ползунок 0…4:

  | Уровень | Поведение |
  | :-- | :-- |
  | 0 Поток | Не поправляет вслух вообще, всё копится в разбор |
  | 1 Мягко | Незаметный рикаст: повторяет мысль правильно, не акцентируя |
  | 2 Баланс (по умолчанию) | В конце реплики даёт одну главную поправку и идёт дальше |
  | 3 Требовательно | Поправляет все заметные ошибки, просит повторить правильный вариант |
  | 4 Дрилл | Перебивает сразу, добивается точного повтора, включая звуки |

- **Что поправлять** — тумблеры: грамматика, словоупотребление, произношение, порядок слов,
  естественность фразы, артикли и предлоги отдельной строкой.
- **Язык поправок** — русский / английский / смешанный (правило по-английски, объяснение по-русски).
- **Язык объяснений в приложении** — ru / en.
- **Русский от ученика** — «только английский» / «можно переспросить по-русски» / «свободно».
- **Инициатива тренера** — ведёт сам / отвечает на вопросы / поровну.
- **Длина урока по умолчанию** — 5 / 10 / 15 / 20 минут / без ограничения.
- **Автоматический разбор после урока** — вкл/выкл.

### 4.3 Уровень

- Текущий CEFR (общий и по навыкам) с датой последней оценки.
- **Зафиксировать уровень вручную** — тумблер + выбор A1…C1 (автокоррекция отключается).
- **Темп усложнения** — консервативный / обычный / агрессивный.
- Кнопка **«Пройти тест заново»** — голосовое placement-интервью ~5 минут.

### 4.4 Аудио и микрофон

- **Режим микрофона** — удержание кнопки / тап-старт-тап-стоп / авто по VAD (hands-free).
- **Чувствительность VAD** и время тишины до конца реплики (0.4–2.0 с).
- **Разрешить перебивать тренера** (barge-in).
- **Шумоподавление и эхоподавление** (NoiseSuppressor / AcousticEchoCanceler).
- **Вывод звука** — динамик / наушники / авто.
- **Громкость тренера**, «медленный повтор» по долгому нажатию на реплику.

### 4.5 Модель и ключ

- Поле **API-ключа** (маскированное) и кнопка «Проверить ключ» — дешёвый тестовый вызов.
- **Модель Live** — список из `ModelCatalog` с подписями «качество голоса / цена / стабильность»,
  по умолчанию `gemini-3.8-live` (native audio).
- **Модель для текстовых задач** — отдельно: `gemini-3.8-flash` для разборов,
  `gemini-3.5-flash-lite` для мелочей.
- **Температура** и лимит длины ответа (advanced).
- **Транскрипция** речи ученика и тренера — нужна для субтитров и разбора.
- **Сжатие контекста и возобновление сессии** — вкл (длинные уроки без обрыва).

### 4.6 Бюджет и лимиты

- Дневной лимит (минуты и/или $), месячный лимит.
- Поведение при достижении: предупредить / мягко завершить урок / заблокировать до завтра.
- Счётчики: сегодня, неделя, месяц; разбивка по типам токенов; оценка $ по тарифам из
  `docs/gemini_live_api.md` (тарифы редактируемы, чтобы не устаревали).
- **Экономия**: не отправлять тишину (VAD), пауза микрофона при сворачивании,
  авто-стоп при бездействии N секунд.
- **Родительский PIN** — закрывает настройки ключа, модели и лимитов.

### 4.7 Данные и приватность

- **Хранить транскрипты** — всегда (по умолчанию) / N дней / не хранить.
- **Записывать аудио** — не записывать (по умолчанию) / только свою речь / весь урок;
  авто-удаление старше N дней; индикатор занятого места.
- Экспорт профиля в JSON/ZIP, импорт, полное удаление данных.
- Экспорт словаря в CSV (совместимо с Anki).

### 4.8 Внешний вид

- Тема: системная / светлая / тёмная; динамические цвета Material You вкл/выкл.
- Размер шрифта субтитров, контрастный режим, «крупные элементы».
- Показывать субтитры: всегда / по тапу / только свои реплики / никогда.
- Анимация голоса: волна / пульсирующий круг / минимализм.

### 4.9 Напоминания

- Время ежедневного напоминания и дни недели.
- Напоминание о готовых карточках словаря.
- Цель в минутах в день, предупреждение о риске потерять стрик, «заморозки» стрика (2 в месяц).

## 5. Слой Gemini Live

### 5.1 Поток данных

```
MicButton ──► LessonViewModel ──► LiveSession ──► LiveWebSocketClient ──► Gemini
                    ▲                  │                    │
                    │                  ├─ AudioRecorder (16 kHz PCM16) ──► realtimeInput
                    │                  ├─ AudioPlayer (24 kHz PCM16) ◄─── serverContent
                    │                  ├─ транскрипты ───────────────────► субтитры + Room
                    │                  └─ toolCall ──► LiveTools ──► Repo ──► toolResponse
                    └──────────── StateFlow<LessonUiState> ───────────────┘
```

### 5.2 Состояние сессии

```kotlin
sealed interface LiveSessionState {
    data object Idle : LiveSessionState
    data object Connecting : LiveSessionState
    data object Ready : LiveSessionState        // setupComplete получен
    data object Listening : LiveSessionState    // микрофон открыт, шлём аудио
    data object Thinking : LiveSessionState     // activityEnd отправлен, ждём ответ
    data object Speaking : LiveSessionState     // проигрываем аудио тренера
    data class Reconnecting(val attempt: Int) : LiveSessionState
    data class Error(val kind: ErrorKind, val message: String) : LiveSessionState
    data object Closed : LiveSessionState
}
```

`ErrorKind`: `NO_KEY`, `INVALID_KEY`, `QUOTA`, `NETWORK`, `PROTOCOL`, `AUDIO_DEVICE`, `BUDGET_LIMIT`.
У каждого — понятный русский текст и конкретное действие («Открыть настройки ключа», «Повторить»).

### 5.3 Setup-сообщение: что важно добавить сверх примера из `docs/gemini_live_api.md`

- `generationConfig.responseModalities: ["AUDIO"]` — для native-audio модели; текст приходит
  через транскрипцию, а не как вторая модальность.
- `inputAudioTranscription: {}` и `outputAudioTranscription: {}` — **обязательно**, иначе не будет
  ни субтитров, ни материала для разбора.
- `speechConfig.voiceConfig.prebuiltVoiceConfig.voiceName` и `speechConfig.languageCode`.
- `realtimeInputConfig.automaticActivityDetection.disabled = true` для push-to-talk: клиент сам
  шлёт `activityStart` / `activityEnd` вокруг нажатия кнопки. В hands-free режиме — серверный VAD
  плюс локальный для экономии трафика.
- `contextWindowCompression` (скользящее окно) — чтобы урок не обрывался по лимиту сессии.
- `sessionResumption: {}` — сервер присылает handle, сохраняем и переподключаемся без потери контекста.
- `systemInstruction` — результат `TutorPromptBuilder`.
- `tools.functionDeclarations` — см. §5.4.

### 5.4 Функции, которые тренер вызывает во время урока

| Функция | Зачем |
| :-- | :-- |
| `save_vocab(term, translation_ru, example, why)` | Слово или выражение, которое стоит выучить |
| `log_mistake(type, original, corrected, explanation, severity)` | Ошибка в живом времени, попадёт в разбор |
| `set_difficulty(direction, reason)` | Ученику слишком легко или тяжело — меняем планку на лету |
| `show_card(kind, text_en, text_ru)` | Вывести на экран карточку-подсказку |
| `suggest_drill(phoneme_or_topic)` | Предложить дрилл произношения или грамматики после урока |
| `end_lesson(reason)` | Тренер сам завершает урок по времени или лимиту |

Ответы на вызовы — мгновенные (пишем в Room и возвращаем `{"ok": true}`), чтобы не ломать темп речи.

### 5.5 Push-to-talk и barge-in

- Нажатие: `AudioRecorder.start()` → `activityStart` → чанки по 100 мс (3200 байт) →
  отпускание → `activityEnd` → состояние `Thinking`.
- Локальный VAD подрезает тишину даже в push-to-talk (экономия входных токенов в 2–3 раза).
- Barge-in: нажатие во время `Speaking` — немедленный `AudioPlayer.flush()` и остановка
  воспроизведения, серверу уходит `activityStart`; приходящий `interrupted: true` подтверждает сброс.
- Удержание против тап-режима — из настроек; в hands-free кнопка становится «паузой микрофона».

### 5.6 Устойчивость

- Экспоненциальный реконнект (1 → 2 → 4 с, максимум 5 попыток) с `sessionResumption` handle.
- Переключение Wi-Fi ↔ LTE — переподключение без завершения урока, индикатор в шапке.
- **Foreground service** типа `microphone` на время урока: запись не умирает при погасшем экране;
  в уведомлении таймер, минуты и кнопка «Завершить».
- Потеря аудиофокуса (звонок) — пауза урока с предложением продолжить.
- Предохранитель: если за 60 секунд не пришло ни одного ответа — сессия закрывается,
  чтобы не жечь бюджет впустую.

## 6. Педагогическое ядро

### 6.1 Сборка системного промпта

`TutorPromptBuilder` — самый важный код в проекте. Структура инструкции:

```
[РОЛЬ]        Ты — {имя}, персональный преподаватель английского. Персона: {персона}.
              Акцент {accent}, темп речи {rate}, реплики {verbosity}.
[УЧЕНИК]      Имя {name}, родной язык русский, уровень {cefr} (speaking {s}, grammar {g}).
              Интересы: {interests}. Цель: {goal}.
[ПАМЯТЬ]      Последние уроки: {3 краткие сводки}.
              Повторяющиеся ошибки: {top-5 с примерами}.
              Проблемные звуки: {phonemes}.
              Слова в проработке: {10 слов из словаря в статусе learning}.
[РЕЖИМ]       {свободный разговор | сценарий: роль, цель, критерии | placement | дрилл}
[СТРОГОСТЬ]   {правила уровня 0..4 из StrictnessPolicy}
[ЯЗЫК]        Говори только по-английски {или: объясняй грамматику по-русски}.
              Не используй лексику выше {cefr+1}.
[ФОРМАТ]      Реплики короткие (1–3 предложения), заканчивай вопросом.
              Ученик должен говорить не меньше половины времени.
              Никогда не читай лекцию длиннее четырёх предложений подряд.
[ИНСТРУМЕНТЫ] Вызывай save_vocab / log_mistake / set_difficulty по ходу разговора, молча.
[ЗАПРЕТЫ]     Не переходи на русский без необходимости, не хвали формально,
              не задавай два вопроса сразу, не исправляй то, что вне списка целей.
```

Промпт кешируется (Context Caching) между уроками одного профиля, пока профиль не изменился.

### 6.2 Разбор после урока

Отдельный вызов `generateContent` с транскриптом и `responseSchema`:

```json
{
  "cefr_estimate": "B1",
  "fluency": 0, "accuracy": 0, "vocabulary_range": 0,
  "summary_ru": "…", "summary_en": "…",
  "mistakes": [{"type": "TENSE", "original": "…", "corrected": "…",
                "explanation_ru": "…", "grammar_topic": "present_perfect", "severity": 2}],
  "vocab": [{"term": "…", "translation_ru": "…", "example": "…", "cefr": "B1"}],
  "pronunciation_notes": [{"phoneme": "/θ/", "words": ["think"], "comment_ru": "…"}],
  "next_lesson_focus": ["…"],
  "praise_ru": "что получилось лучше, чем в прошлый раз"
}
```

Результат раскладывается по таблицам и показывается экраном «Разбор урока».
Стоит доли цента, поэтому включено по умолчанию.

### 6.3 Определение уровня

- **Placement-интервью**: режим урока, где промпт ведёт по нарастающей сложности
  (бытовое → абстрактное → гипотетическое), ~5 минут, в конце `end_lesson` и разбор с
  обязательной оценкой по навыкам.
- **Автокоррекция**: скользящее среднее CEFR-оценок последних пяти уроков; повышение уровня —
  только после трёх подряд оценок выше текущего (защита от скачков). При `levelLocked = true`
  оценки показываются, но профиль не меняется.

### 6.4 Адаптация в реальном времени

Тренер вызывает `set_difficulty(UP|DOWN)`, когда ученик отвечает односложно и с паузами (вниз)
или свободно и точно (вверх). Приложение записывает событие, в текущей сессии возвращает
`toolResponse` с новым целевым уровнем, а после урока корректирует профиль.

## 7. Модули

### 7.1 Словарь с интервальным повторением

- Алгоритм **SM-2** (просто и предсказуемо), с заделом на переключение на FSRS.
- Источники карточек: `save_vocab` из урока, разбор урока, ручное добавление, упражнения.
- Режимы: узнать перевод → вспомнить слово → **произнести вслух** (проверка локальным
  `SpeechRecognizer`, бесплатно) → услышать и понять (системный TTS).
- Оценки: «не помню / трудно / хорошо / легко».
- Работает **полностью оффлайн**.
- Экран: очередь на сегодня, прогресс-кольцо, свайп-жесты, «отложить».

### 7.2 Ролевые сценарии

- Каталог карточек: категория, уровень, описание, ориентировочная длительность.
- Сид-набор (`assets/scenarios.json`): кафе, аэропорт, отель, врач, собеседование, созвон с
  командой, магазин, знакомство, спор о фильме, жалоба на сервис, small talk у лифта.
- У каждого сценария: роль тренера, роль ученика, цель («добиться возврата денег»),
  словарь-подсказка, критерии успеха для разбора.
- **Свои сценарии**: пользователь пишет описание, текстовая модель достраивает остальное,
  запись сохраняется с `isCustom = true`.
- В конце — оценка «цель достигнута / частично / нет» плюс обычный разбор.

### 7.3 Тренажёр произношения

- Три режима:
  1. **Повтори за тренером** — фраза, эталонное аудио, запись ученика, оценка и сравнение.
  2. **Минимальные пары** — ship/sheep, bad/bed, thin/sin: и на слух, и на произнесение.
  3. **Проблемные звуки** — фокус на фонемах с низким `phoneme_score`, подборка слов.
- Оценка: короткая Live-сессия в режиме «фонетический коуч»; промпт просит вернуть оценку и
  конкретную артикуляционную подсказку по-русски («язык между зубами, это не /s/»).
- Визуализация: карта фонем английского с цветом по освоенности.
- Свои попытки можно переслушать, если включена запись аудио.

### 7.4 Грамматика и упражнения

- Темы подтягиваются из ошибок: три повтора `present_perfect` за неделю — тема поднимается
  в «Рекомендовано».
- Карточка темы: краткое объяснение на русском с примерами и 5–10 упражнений, сгенерированных
  **на материале собственных ошибок ученика** (его фразы, исправленные).
- Типы: заполнить пропуск, выбрать вариант, собрать предложение, перевести с русского,
  произнести фразу правильно.
- Генерация — пакетом (10 упражнений за вызов) в фоне через WorkManager, чтобы упражнения
  были готовы заранее и работали оффлайн.
- `mastery` растёт по доле верных ответов и падает при новых ошибках по теме.

Кнопка по состояниям: `Ready` — «Держите, чтобы говорить»; `Listening` — пульсирует и показывает

Дополнительно: долгий тап по реплике тренера — «повторить медленнее»; кнопка «не понял» —
тренер переформулирует проще; кнопка «как сказать…?» — быстрый текстовый ввод, тренер
подсказывает фразу, не ломая разговор.

### 8.3 Остальные экраны

- **Старт урока**: выбор режима (свободный разговор / сценарий / placement), темы, длительности;
  предпросмотр «тренер сегодня: персона, голос, строгость»; оценка стоимости («≈ $0.20 за 10 минут»).
- **Разбор урока**: сводка, оценки по шкалам, лента ошибок с фильтром по типу, «взять слова
  в словарь» одним тапом, «создать упражнения по теме», «повторить этот сценарий».
- **Прогресс**: минуты по дням, кривая CEFR, топ ошибок, карта фонем, объём словаря по статусам,
  расходы за месяц с разбивкой.
- **Онбординг**: имя → интересы и цель → персона и голос → API-ключ (с инструкцией, как получить
  в Google AI Studio) → разрешение на микрофон → placement-интервью.

### 8.4 Дизайн-система

- Material 3 Expressive; существующая палитра `Color.kt` (индиго / циан / янтарь) как запасная,
  по умолчанию — динамические цвета Material You.
- Роли цвета: primary — действия ученика и микрофон; secondary — речь тренера; tertiary —
  поправки и достижения; error — **только** технические ошибки приложения. Ошибки ученика
  никогда не красим в красный: это демотивирует, для них tertiary.
- Типографика: крупные заголовки, субтитры от 18sp с настраиваемым размером.
- Движение: волна голоса на Canvas по амплитуде PCM, появление карточек поправок через
  `AnimatedVisibility` + `slideInVertically`, пульсация кнопки в ритме речи.
- Доступность: интерактивные элементы ≥ 48dp, `contentDescription`, поддержка TalkBack,
  режим крупных элементов.

## 9. Учёт расходов

- `TokenMeter` читает `usageMetadata` из ответов (а не только считает по формулам) и пишет
  в `usage_log`; формулы из `docs/gemini_live_api.md` используются для оценки в реальном времени.
- Ориентиры: голосовой разговор ≈ **$0.021/мин** (~$1.26/час), 10-минутный урок ≈ $0.21;
  разбор урока и генерация упражнений — доли цента.
- Тарифы вынесены в редактируемые настройки, чтобы не протухли.
- Перед уроком показывается ожидаемая стоимость; на 80 % дневного лимита — ненавязчивое
  предупреждение, на 100 % — поведение из настроек.
- Экран «Расходы»: сегодня / месяц, разбивка по типам токенов, самые дорогие уроки.

## 12. Тестирование

- **Unit**: `TutorPromptBuilder` (снимки промптов для разных профилей), планировщик SM-2,
  `TokenMeter`, `StrictnessPolicy`, парсер Live-протокола на записанных JSON-ответах.
- **Room**: миграции и запросы (`androidx.room:room-testing`).
- **Fake-режим**: `FakeLiveSession`, проигрывающая записанный диалог, — позволяет разрабатывать
  и тестировать экран урока **без единого запроса к API** (экономия и пригодность для CI).
- **Compose UI-тесты**: экран урока по состояниям, экран настроек.
- **Ручной чек-лист**: обрыв сети, входящий звонок, выключение экрана, отказ в разрешении,
  неверный ключ, исчерпанный лимит.

## 13. Риски

| Риск | Смягчение |
| :-- | :-- |
| Имена моделей и версия Live API меняются | Модель и путь API — в конфиге и настройках, не в константах |
| Лимит длительности Live-сессии | `contextWindowCompression` и `sessionResumption` с первого дня |
| Расход батареи и нагрев на длинном уроке | Push-to-talk по умолчанию, VAD, foreground service, замер на M8 |
| Оценка произношения моделью субъективна | Не показывать проценты как истину: формулировки «стало лучше/хуже» и конкретные звуки |
| Ребёнок случайно сожжёт бюджет | Дневной лимит плюс родительский PIN на настройках ключа |
| `minSdk 35` отрезает устройства | Снижаем на M0 |
| Транскрипты хранят личные разговоры | Хранение настраивается, аудио по умолчанию выключено, всё только локально |

## 14. Что сознательно не делаем

- Видео и камеру — решено: только аудио и текст; CameraX убираем из зависимостей.
- Свой backend, аккаунты и облачную синхронизацию — ключ у каждого свой.
- Публикацию в Play Store, монетизацию, аналитику, сторонний краш-репортинг.
- Собственную ASR или фонетическую модель — опираемся на Gemini и системное распознавание.
